# Agri-food CO2 Emissions — ML Pipeline

Predicting total agri-food CO2-equivalent emissions (kt) from year and population demographics using 7 machine learning models.

**Course:** MSIS 522 — HW1

## Dataset

- **Source:** FAO Agri-food CO2 Emission Dataset
- **File:** `Agrofood_co2_emission.csv`
- **Size:** 6,965 rows × 31 columns (236 countries, 1990–2020)
- **Target:** `total_emission` (kt CO2-eq)
- **Features used:** Year, Rural population, Urban population, Total Population - Male, Total Population - Female

> The 23 emission-source columns were excluded because `total_emission` is their exact sum (target leakage).

## Models

| Model | Test R² |
|-------|---------|
| Linear Regression | 0.8711 |
| Lasso | 0.8711 |
| Ridge | 0.8716 |
| CART (Decision Tree) | 0.9603 |
| Random Forest | **0.9775** |
| LightGBM | 0.9730 |
| MLP (Neural Network) | 0.8861 |

All models except MLP were tuned via GridSearchCV with 5-fold cross-validation.

## Setup

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Train models (generates the `models/` directory)

```bash
python train_models.py
```

This takes a few minutes. It will:
- Load and preprocess the dataset (70/30 split, median imputation, scaling)
- Tune hyperparameters via GridSearchCV for Lasso, Ridge, CART, Random Forest, and LightGBM
- Train a PyTorch MLP with early stopping
- Compute SHAP values for Random Forest and LightGBM
- Save all artifacts to `models/`

### 3. Run the Streamlit app

```bash
streamlit run app.py
```

The app opens at [http://localhost:8501](http://localhost:8501).

## Streamlit App Tabs

1. **Executive Summary** — Dataset description, why it matters, approach, key findings
2. **Descriptive Analytics** — Target distribution, feature visualizations with captions, correlation heatmap
3. **Model Performance** — Comparison table, bar charts, hyperparameters, CART tree, MLP training history, actual-vs-predicted plots, residuals, linear coefficients
4. **Explainability & Interactive Prediction** — SHAP beeswarm/bar/waterfall plots, interpretation, interactive sliders for real-time prediction with SHAP explanation

## Deployment

To deploy on Streamlit Community Cloud:

1. Push this directory to a GitHub repository (include the `models/` directory)
2. Go to [share.streamlit.io](https://share.streamlit.io)
3. Connect your GitHub repo, set `app.py` as the main file
4. Deploy

> **Note:** The `models/` directory must be committed to GitHub. The app loads pre-trained models and does not retrain them.
